# Roadmap

## Phase 1: Foundation (Current)
- Establish project architecture and documentation.
- Initialize Flutter frontend and Spring Boot backend.
- Set up PostgreSQL and Docker Compose for local development.
- Configure base entities and database schema.

## Phase 2: Core Authentication & User Management
- Implement JWT-based authentication in backend.
- Create user registration and login endpoints.
- Build Flutter login/registration screens.
- Manage secure token storage and session state.

## Phase 3: Action Catalog & Tracking
- Seed database with sustainable actions.
- Build backend APIs for listing and logging actions.
- Implement Flutter UI for viewing actions and submitting logs (with photo/location evidence).

## Phase 4: Verification Engine (V1)
- Build core verification pipeline in backend.
- Integrate location-based verification (Geofencing).
- Set up basic duplicate detection.

## Phase 5: Rewards System
- Seed database with rewards.
- Build backend APIs for listing and redeeming rewards.
- Implement Flutter UI for reward catalog and redemption flow.

## Phase 6: AI Verification Integration
- Integrate AI service (e.g., Google Cloud Vision or custom model) for photo evidence analysis.
- Update verification engine to utilize AI confidence scores.
